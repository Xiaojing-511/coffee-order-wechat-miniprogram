# 上线检查清单（对外售卖版）

## 一、资质与主体（对外售卖的前提，缺一不可）

- [ ] **非个人主体小程序**：个人主体无法通过售卖/餐饮类目审核，需用个体工商户或企业主体注册小程序（如主体变更，云开发环境需重新绑定）
- [ ] **服务类目**：餐饮服务（咖啡厅/茶饮/饮品店），需提交营业执照、食品经营许可证等资质
- [ ] **微信支付商户号**：当前为**模拟支付**，可完整演示点单流程；接入真实收款需商户号（主体与小程序一致），届时把 `order` 云函数的 `pay` 动作替换为微信支付统一下单即可
- [ ] **隐私政策**：已随项目更新（`pages/privacy/privacy.wxml`），上线前复核文案与联系方式

## 二、技术部署（本机/云端）

- [ ] 云函数全部部署（开发者工具右键 -> 上传并部署：云端安装依赖）：
  - `login`（身份 + 商家信息）
  - `migrate`（一次性建库：集合 + 创始人白名单 + 演示数据）
  - `menu`（商家菜单管理 + 演示数据导入）
  - `order`（下单/支付/取消/订单流转）
  - `storeQr`（店铺小程序码）
- [ ] 运行一次 `migrate`（云端测试输入 `{}`）
- [ ] 开通「生成小程序码」云调用权限（`wxacode.getUnlimited`），`functions/storeQr/config.json` 已声明
- [ ] 按 [database-rules.md](./database-rules.md) 配置数据库权限规则
- [ ] 发布正式版（店铺码扫码后才可正常打开）

## 三、商家开通流程（运营 SOP）

1. 商家付费（线下收款）后，在小程序「我的」页复制自己的 openid 发给你；
2. 你在云开发控制台 `merchants` 集合添加记录：
```json
{
  "openid": "商家openid",
  "storeId": "S2001",
  "storeName": "商家店名",
  "plan": "month",
  "status": "active",
  "expireTime": 1767225600000,
  "createTime": 1724200000000
}
```
3. 商家打开小程序即进入商家端（tabBar：订单/饮品/我的），可设置店铺信息、生成店铺码、管理菜单与订单；
4. 到期处理：`expireTime` 过期后，云函数写操作自动拒绝并返回「服务已到期」，小程序端弹续费提示；续费时更新 `expireTime` 即可。
