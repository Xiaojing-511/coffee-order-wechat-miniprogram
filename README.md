# 饮品备忘录 - 个人饮品记录工具

## 项目简介

**饮品备忘录**是一款个人自用的工具类小程序，用于记录个人饮品的名称、卡路里、口味偏好等信息，帮助用户了解和统计自己的饮品消费情况。

## 合规说明

### 微信小程序审核合规性

**定位明确**：
- 应用类型：个人自用工具
- 服务类目：工具 > 备忘录/记事本
- 使用场景：个人健康管理、饮食记录

**无商业属性**：
- ❌ 无点餐、订单、支付功能
- ❌ 无价格、金额、收款功能
- ❌ 无门店、顾客、客户相关内容
- ❌ 无外卖、预约、取餐功能
- ❌ 无优惠、会员、活动营销

**功能特点**：
- ✅ 饮品名称、分类、卡路里记录
- ✅ 温度、糖度、口味偏好设置
- ✅ 个人记录查看和统计
- ✅ 日报数据生成

**数据安全**：
- 数据存储在腾讯云开发，仅用户本人可访问
- 数据采用 openid 隔离机制，确保数据安全
- 不收集任何设备信息、位置信息等敏感数据
- 不涉及第三方数据接口

**隐私保护**：
- 仅在用户主动录入时收集数据
- 数据仅用于个人记录和统计
- 不用于商业目的、营销推广或第三方共享
- 用户可随时删除自己的数据

## 核心功能

### 1. 饮品管理
- **分类管理**：自定义饮品分类（如咖啡、茶饮、果汁等）
- **饮品管理**：添加、编辑、删除饮品信息
- **卡路里记录**：为每个饮品设置标准卡路里值

### 2. 记录功能
- **待选列表**：暂存多个饮品，统一提交
- **立即记录**：选择饮品后直接记录
- **详细选项**：支持选择温度（冷/热）、糖度（无糖/少糖/正常糖/多糖）
- **备注功能**：可为每个记录添加自定义备注

### 3. 记录查看
- **今日记录**：查看当天的所有饮品记录
- **全部记录**：查看历史所有记录
- **详情查看**：查看单条记录的完整信息
- **删除记录**：支持删除错误的记录

### 4. 数据统计
- **今日统计**：显示今日记录数、总热量、饮品数
- **历史日报**：生成每日统计数据报表
- **数据归档**：生成日报后清空今日数据

### 数据集合设计

#### `categories` - 分类集合
```javascript
{
  _id: String,
  name: String,           // 分类名称
  createTime: Number      // 创建时间戳
}
```

#### `drink_items` - 饮品集合
```javascript
{
  _id: String,
  name: String,           // 饮品名称
  calories: Number,       // 卡路里（kcal）
  description: String,   // 描述
  category: String,       // 所属分类
  imageUrl: String,       // 图片云存储ID
  createTime: Number,     // 创建时间
  updateTime: Number      // 更新时间
}
```

#### `records` - 记录集合
```javascript
{
  _id: String,
  recordNumber: Number,   // 记录编号
  items: Array,          // 饮品列表
    - id: String,        // 饮品ID
    - name: String,      // 饮品名称
    - calories: Number,   // 单品卡路里
    - quantity: Number,   // 数量
    - temperature: String,// 温度（冷/热）
    - sugarLevel: String, // 糖度
    - remark: String     // 备注
  totalQuantity: Number, // 总数量
  totalCalories: Number, // 总热量
  status: String,        // 状态
  createTime: Number,    // 创建时间
  dateString: String     // 日期字符串
}
```

#### `daily_reports` - 日报集合
```javascript
{
  _id: String,
  date: String,          // 日期
  recordCount: Number,   // 记录总数
  totalCalories: Number, // 总热量
  drinkCount: Number,    // 饮品总数
  createTime: Number     // 生成时间
}
```

## 使用说明

### 1. 首次使用
1. 打开小程序，进入**饮品管理**
2. 创建饮品分类（如：咖啡、茶饮）
3. 添加饮品信息（名称、卡路里、分类）
4. 开始记录饮品摄入

### 2. 记录饮品
1. 在首页点击"开始记录"或通过"饮品管理"选择饮品
2. 设置温度（冷/热）、糖度（无糖/少糖/正常糖/多糖）、数量
3. 添加备注（可选）
4. 点击"立即记录"保存到历史记录
5. 或点击"加入待选"暂存，稍后统一提交

### 3. 查看记录
1. 在首页点击"查看记录"进入记录列表
2. 查看今日记录或全部历史记录
3. 点击单条记录查看详细信息
4. 可删除错误的记录

### 4. 数据统计与日报
1. 在首页点击"日报统计"查看统计数据
2. 系统自动统计今日记录数、总热量、饮品数
3. 点击"生成本日日报"生成日报报表
4. 生成日报后今日数据自动归档清空

### 5. 隐私设置
1. 在首页底部点击"隐私政策"
2. 查看完整的隐私政策和用户协议

## 数据库安全规则

数据库权限已配置为**仅创建者可读写**，确保数据安全：

```javascript
{
  "read": "auth.openid == doc._openid || auth.openid == null",
  "write": "auth.openid == doc._openid"
}
```

**规则说明**：
- 读取：仅创建者或未登录用户可读
- 写入：仅创建者可写
- 禁止匿名写入，确保数据安全
